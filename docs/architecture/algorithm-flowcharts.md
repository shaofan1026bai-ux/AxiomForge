# 算法流程图模块

入口为“当前项目 → 算法与规则”。图示帮助阅读、编辑及交流算法逻辑，不发布执行代码或下发设备控制。

## 基本操作

1. 选择当前项目的图示，或新增流程图并填写名称、说明。
2. 在“Mermaid源码”中粘贴或编辑flowchart／graph文本，点击“更新预览”。
3. 预览成功后可浏览画布，点击节点查看说明；放大、缩小和平移不修改源码。
4. 点击保存形成新的图示版本。未保存草稿和已保存版本有独立状态，不以旧预览替代新草稿。
5. 选择已保存版本后导出SVG，得到整张图而不是当前画布的裁切截图。

语法错误时保留上次有效图并标明预览已过期；修正源码并更新预览后再保存。切图、版本、项目或离开模块时保护未保存内容。保存失败或版本冲突保留草稿，不自动丢弃。

## 航信首个样例

“AHU运行策略”保留用户提供的9个节点、9条边：夜间范围→人员／航班保障／预冷→回风温度→AHU运行→冷水机组状态→新风阀动作。

- T、C为黄色可配置条件，保留原始classDef样式，同时有文字说明。
- 夜间具体时段与温度设定值均待关联，图中没有填写或推断实际运行参数。
- N表示“关闭所有AHU及新风阀”，B表示“关闭对应AHU及新风阀”；实际设备清单未绑定。
- 样例只属于航信。华师大、大润发的算法目录初始为空，可各自建立图示，不共享航信内容。

## 图示、预览与版本

“图示版本”独立于可执行算法版本。名称、说明、源码和节点注释属于图示内容；主题与画布视口属于展示状态。

每次保存使用当前版本作为基线，创建不可变新版本；不改写历史。以旧版本为起点编辑时会记录派生关系，不将旧版本变成最新的原地修改。两个浏览器基于同一旧版本保存时，后保存者必须处理冲突。

已保存图示使用本机SQLite持久化，默认位于`.nicegui/algorithm-flowcharts.sqlite3`，该目录已被Git忽略。这里不保存账号、密码、Token或现场运行数据。更换运行目录或清理`.nicegui`会影响本机持久化资料，应与普通代码文件区分。

未保存草稿仅属于当前浏览器，不承诺崩溃后恢复。图示保存后刷新或重启可重新读取。

## SVG与渲染边界

首版覆盖Mermaid流程图，不包含任意HTML、外部链接、脚本、自定义初始化配置或其他图类型。普通中文节点、是／否分支、子图及受限节点样式可使用；源码最多64KiB，图示最多100个节点／200条边，超限由编辑器反馈。

画布使用本地打包的Mermaid引擎，不向外部图示服务发送源码。展示前及导出边界检查SVG活动内容；导出包含项目、名称及版本，保留完整viewBox，不受当前缩放和平移影响。

## 与其他模块的关系

流程图不调用小麦或航班接口，不显示算法正在执行或实际命中路径。参数修改驱动运行、代码自动转图、实时路径、PNG／PDF导出、删除版本及跨项目复制不在首版范围。

工作台仍使用原主题和项目导航。部署／预览重启继续使用统一启动入口，保留航班与小麦两类数据源参数，避免新模块启动影响已有专题。

全屏依赖浏览器支持；不可用时显示提示并继续使用普通画布。首屏按可读倍率显示，长图可缩放、平移或点击适应窗口查看全貌。

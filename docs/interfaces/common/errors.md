# 错误与重试

区分网络/HTTP 错误、业务错误和设备执行错误。HTTP 成功不一定代表业务或控制执行成功。

| 系统/范围 | HTTP 状态 | 业务码 | 含义 | 是否可重试 | 处理方法 |
|---|---|---|---|---|---|
| 待填写 | 待填写 | 待填写 | 待填写 | 是/否/待确认 | 待填写 |

## 整理原则

- 记录超时、限流、鉴权失效、对象不存在、设备离线等情况。
- 查询接口说明可重试条件、次数、间隔以及限流要求，不默认无限重试。
- 控制超时可能表示“执行结果未知”，不能直接认定执行失败。
- 控制接口只有在明确支持幂等或能确认未执行时，才可按其约定重试；不明确时先查状态。
- 系统和具体接口的错误码、重复调用行为，写在对应文档并链接到这里。

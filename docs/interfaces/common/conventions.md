# 跨系统数据约定

这里只记录已确认的跨系统共识。没有统一的内容写“各系统单独说明”。

| 项目 | 约定 |
|---|---|
| 时间格式与时区 | 待填写；区分时间戳秒/毫秒、带时区/不带时区 |
| 时间范围边界 | 待填写；是否包含起止时间 |
| 数据时间含义 | 待填写；采集时间、入库时间或统计周期 |
| 单位和精度 | 待填写；区分原始值和换算后值 |
| 缺失与异常值 | 待填写；null、空字符串、0、特殊数值分别代表什么 |
| 排序与重复数据 | 待填写 |
| 分页与单次上限 | 待填写 |
| 数据新鲜度 | 待填写；延迟、质量标识和过期判定 |
| 对象标识 | 待填写；系统/站点/设备/测点 ID 的关系 |

接口自己的约定与这里不同时，应在接口文档中明确说明。

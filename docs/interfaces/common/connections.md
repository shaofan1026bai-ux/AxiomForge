# 连接与鉴权

本文件定义连接文档的公共填写方式；各项目的实际连接说明填写到 `projects/<project-id>/connections.md`，不在这里维护第二份现场配置。只保存连接方式和凭据引用，不保存真实凭据。以下变量名仅是示例，不是已经实现的配置机制。

| 项目 ID | 连接 ID | 系统 ID/版本 | 环境 | 基础地址引用 | 鉴权方式 | 凭据引用 | 平台项目/租户参数 |
|---|---|---|---|---|---|---|---|
| 待填写 | 待填写 | 待填写 | 测试/实际 | 待填写 | Bearer/API Key/签名/其他 | 例如 `PROJECT_TEST_API_TOKEN` | 待填写/不适用 |

每个系统还应补充：

- 鉴权放在请求头、查询参数还是请求体，字段名是什么。
- Token 获取、有效期、刷新和失效后的处理方式。
- 是否需要 VPN、专网、代理或证书。
- 查询和控制是否使用不同账号或权限。
- 测试环境是否真的隔离设备控制；无法确认时标记“待确认”。

生产地址如涉及敏感信息，也使用本地配置引用。响应样例中的账号、地址和对象标识按需要脱敏，并保持各文档中的示例映射一致。

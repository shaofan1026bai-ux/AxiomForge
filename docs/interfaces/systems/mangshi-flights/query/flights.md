# 查询本场与相邻计划日的航班

- 接口 ID：`mangshi-flights.query.plan-days.v1`
- 状态：已验证（2026-11-04，芒市 LUM 当前源库）
- 用途：航信项目的今日航班双栏及长间隔视图。
- 调用：`load_flights(day: date) -> FlightSnapshot`，通过后台I/O线程调用。

## 查询

```sql
SELECT * FROM flight WHERE airptIataCd = $airport AND planDate IN $dates;
```

固定参数 `airport=LUM`；`dates` 为所选日前一天、当天和后一天，格式 `YYYY-MM-DD 00:00:00`，与本源表字符串字段一致。不使用 `ts` 时间窗口或 `LIMIT` 截断记录。不得将此字段类型假定推广到其他数据库。

原参考包的 `ts` 四日窗口查询在 2026-11-04 18:25 返回1015条；补查三个计划日返回772条（昨天253、今天258、明天261）。今日按最新版本与共享号整理后79条有效主航班，进港39／出港40，本场已有实际时刻59条。这些数字是验证快照，不是固定业务常量。

## 数据字段

| 字段 | 用途 |
|---|---|
| `planDate` | 业务计划日，允许包含次日到达 |
| `flightNum`、`arrDepFlag` | 航班号、I进港／O出港 |
| `origAirptCd`、`destAirptCd` | 路由与本场归属；进港终点／出港起点必须为LUM |
| `depCtyChnNm`、`arrvCtyChnNm` | 展示航线，缺失时用机场代码 |
| `schdArrvDt`、`estmtArrvDt`、`arrvDt` | 进港计划／预计／实际本场到达 |
| `schdDptDt`、`estmtDptDt`、`dptDt` | 出港计划／预计／实际本场起飞 |
| `regulatoryPlatformSysDataTime` | 来源更新时刻，多版本选择参考 |
| `fltShrInd` | 共享主号引用，需同时匹配计划日、方向、航线 |
| `dataOperation` | 最新版本为DELETE时排除主号 |
| `fltStat`、`fltStatChnNm` | 保留方向语义；任一为非营运时排除 |
| `gate` | 仅出港展示；进港可能是外站登机口 |
| `ts` | 不用于业务日、本场事件或来源更新时间 |

无偏移量业务时刻按Asia/Shanghai解释；带偏移量时刻转为北京时间。缺失不使用0代替。本场实际时刻优先用于状态，出港在目的站“到达”不解释为本场进港。

## 整理与空档

1. 按计划日／航班号／方向／起降机场分组，取来源更新时间最新的版本，同时间用记录ID稳定排序。
2. 同范围共享号匹配主号后合并；有效但找不到主号的记录保留并显示警示，不猜测跨日关系。
3. 排除删除与非营运记录，保留缺失时间与状态冲突的可见说明。
4. 计划间隔使用本场计划时刻；动态间隔使用实际→预计→计划并明确回退顺序。
5. 合并全部进出港，相同时刻分组，计算相邻事件之间时长。相邻计划日参与分割，至少一端属于所选计划日才展示。
6. 不受航班列表的方向／城市／状态筛选影响；不从缺失记录外推首末边界空档。

相邻计划日补查减少跨日遗漏，不证明上游无漏报或不存在更远跨日事件。间隔只供评估；到港后保障、出港前准备尚未配置，不输出可停机时长或设备指令。

## 配置与失败

启动参数 `--flight-env-file /path/to/project.env`，或设置 `AXIOMFORGE_FLIGHT_ENV_FILE`；连接字段沿用参考包的 `SURREALDB_*`，环境变量优先，关闭dotenv插值。账户权限由数据库配置维护，程序固定SELECT不等于账户本身只读。

错误统一为 `FlightSourceError`，不暴露底层异常、地址、SQL或凭据。页面失败保留旧快照并显示错误，成功空数组显示空结果。认证、TLS、网络错误不得当作空航班成功。

## 国内／国际与区域分组（2026-11-05补充）

当前源库`fcategory=0`映射国内，`fcategory=1`映射国际。11月4日有效主航班核对为国内77班／国际2班，国际为DR5037（LUM→MDL）及DR5038（MDL→LUM）。这是样本核对，尚未取得源系统正式枚举字典；其他值或缺失均显示待确认，不默认为国内。`fltAttr`的I/O在样本中对应进出方向，不能用它判断国内／国际。

用户确认有分别对应的进出港区域，页面新增国内进港、国内出港、国际进港、国际出港四个范围，并保留全场合并。区域选择影响时间带、间隔计算和列表；列表的搜索／状态／方向过滤不改变计算范围。同方向属性未知的航班参与区域空档的保守阻断并独立标识，避免生成虚假长空档。区域分组尚未配置设备对应关系或保障时长。

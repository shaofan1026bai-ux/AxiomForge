# 五台AHU回风历史与统计

沿用[历史查询接口](history.md)的POST路径、Bearer鉴权和成功信封，但属于独立分析合同，不改变功率专题的2分钟／7天限制。

## 身份与输入

项目832，设备12783～12787对应AHU1～5，每台读取`ewcnad_msahu{n}_airin`（℃）、`ewcnad_msahu{n}_v20`（无量纲）、`ewcnad_msahu{n}_v01`（hz）。每轮独立校验授权与激活点位归属，15点批量查询，`interval=1`；每个业务日期最多一个不超过24小时的窗口，当前最多62个开始日期。1分钟只是查询网格，不代表实际上报周期或瞬时原始值。

用户日期两端包含；窗口左闭右开。全天截至结束日期的次日00:00；跨午夜按开始日归属，如10月1～3日22:00—次日06:00，最后结束10月4日06:00。未来窗口、相等时刻、逆序／超限日期在登录前拒绝。每请求15秒超时，整轮900秒截止；所有窗口成功才发布快照。取消停止后续片及结果发布，不能撤回已发送请求。

## 计算与质量

三点按精确同刻配对；反馈=1且0<频率≤60Hz确认开机，反馈=0且频率=0确认停机，其余区分矛盾或未知。温度有效但缺少状态仍计入不限启停，不能计入开机。空、冲突和非法值不补0、不前向填充；有限真实0保留。重复同值去重，异值字段失效。

极值／样本平均及P05、P95来自完整有效输入，分位数按`(n-1)*p`线性插值；总分位数不平均日分位数。温区左闭右开，比例为有效采样占比，不是时长；质量分母仅含选中窗口的预期网格，未选时段不算缺测。

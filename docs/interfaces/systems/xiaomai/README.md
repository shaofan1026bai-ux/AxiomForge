# 小麦设备与测点只读接口

- 系统 ID／版本：`xiaomai/v1`，v1为本项目整理版本，不代表厂商版本。
- 用途：查询授权项目、设备测点及历史数据，为功率与室外温度、五台AHU回风温度及每日用电占比分析提供来源。
- 状态：2026-11-06 已在航信环境只读实查；不代表其他域名、租户或控制接口已验证。
- 来源：用户提供的《航信基础接口.md》《丽娃AI-登录逻辑-20261106.zip》及当前账号实查。凭据不复制到仓库。
- 实际域名、项目及测点映射见[航信连接](../../projects/hangxin-airport/connections.md)与[现场字典](../../projects/hangxin-airport/dictionary.md)。

## 对象和调用范围

登录响应给出公司及用户信息，项目列表确定授权范围；设备与测点归属需逐层校验。不同部署可能复用对象数字ID，不能把参考包中的公司、项目或设备编号直接移植到航信环境。

功率专题固定使用用户指定的两条测点；AHU专题登记五台设备的回风、运行反馈、频率共15点。不在每次刷新时遍历整套设备目录。源地址必须保留端口36443，使用HTTPS校验证书；不能用关闭验证解决本机证书信任差异。

## 时间与边界

接口使用不带时区的日期时间字符串，本项目按现场时间 `Asia/Shanghai` 解释并标注。2分钟间隔已实查；返回点值的采集／统计语义、质量标志及官方时间说明尚待补充，不据此计算能量或自动诊断传感器。

AHU使用独立1分钟查询网格，2026-11-09完成15点短范围及39日逐窗口实查；实际很多时刻约每2分钟才有有效值，空网格不插值。日期范围可叠加每日时段，跨午夜按开始日期归属且末日延伸次日；当前限制62个开始日期，最长总截止900秒，39日15点实查约84秒。分片失败不发布部分总体统计。详见[AHU历史与统计](query/ahu-temperature.md)。

HTTP成功与业务成功分别检查。查询失败不转换为空结果；错误信息脱敏，Token不导出。当前工作台采用手动查询、不自动重试或轮询，不提供设备写入能力。

每日用电专题使用固定八项、13块物理表的累计电量点，1分钟网格、完整自然日、唯一日界和独立区间口径。缺测不归一化、不均摊；详见[每日用电统计](query/energy-share.md)。

AHU 二氧化碳与启停专题读取同一台设备的 CO₂、回风温度、运行反馈、频率、新风阀开度和 CO₂ 设定值。详见[点位与分析口径](query/ahu-co2.md)。

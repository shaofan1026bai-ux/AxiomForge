# 航信区域温湿度

## 范围

`region_climate_source.py` 登记七区室内探头与服务 AHU，`region_climate.py` 基于自然日快照计算趋势、开机前后范围和温度越线。页面在航信机场项目下使用。

## 接口

- `load_region_climate(day, *, cancelled=None, settings=None, transport=None)` 返回 `ClimateSnapshot`，包含北京时间半开窗口、探头温湿度和五台 AHU 状态序列。
- `analyze_region(snapshot, region, *, lower=22, upper=26, probe_id=None)` 返回 `RegionAnalysis`，含趋势、开机对照与越线时段。

## 数据合同

- `REGIONS` 维护制冷映射。26 个已核实探头按完整测点 ID 查询，两项名称待确认的探头保留展示且不参与聚合。源复用小麦只读客户端，校验项目 832、设备归属、单位及响应。所有批次成功才发布。
- 按北京时间自然日查询，今天取到已完成分钟。五分钟桶内先算单探头均值，再对该区域有效探头等权平均。温、湿独立计数，缺测留空。上下限为可编辑观察阈值，严格低于或高于才计越线。
- 温区分布复用 AHU 回风专题的七个固定温区。区域按每桶区域均温计数，探头按每桶单探头均温计数，各行分母为自己的有效温度桶。缺测不计入分母，无样本和待确认行保留且不绘制占比。过冷过热观察线不改变固定温区。
- 按时间展示的温区方格支持 5、15、30 分钟，自北京时间零点对齐。粗粒度时段取其中有效五分钟均温的算术平均。记录有效和应有五分钟桶数，缺测与待确认显示空值，最后一格截止到查询快照结束时间。
- 开机基于相邻可信停机与开机反馈，单个状态或长缺口不能推断开启。前后以 60 分钟为观察上限，并受日界和运行周期限制。对照使用前后均有温度的共同探头，显示实际窗口、温区和有效样本数。

## 校验与错误

| 条件 | 行为 |
| --- | --- |
| 日期无效、未来或没有已完成分钟 | 查询前拒绝 |
| 认证、测点身份或任一历史批次失败 | 脱敏提示，保留旧快照 |
| 缺测或状态矛盾 | 图表留缺口，分开越线段，开机判定不跨状态矛盾 |
| 上下限不合法 | 保留上次有效观察阈值 |

## 场景

切换到二层登机通道仅看该区域的五个探头，即使近机位候机厅与候机厅也由 AHU3 服务。查看同一天的两次启动时应分别列出可比较的前后窗口。单探头越线可以独立出现在区域异常列表。

## 验证

覆盖区域等权均值、稀疏运行反馈、同一组探头对照和缺测断段。真实查询抽查七区探头覆盖和五台 AHU 状态。浏览器验证手动查询、区域与探头切换、阈值重算和主题。

## 常见错误

把同一 AHU 服务的多个区域合并会掩盖局部热区。区域趋势按所选区域探头聚合，AHU 状态仅用于时间轴和开机事件对照。

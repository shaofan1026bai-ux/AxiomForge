# AHU 回风温度只读合同

## 1. 范围与触发

修改`ahu_temperature.py`、`ahu_temperature_source.py`或相关源复用能力时阅读。适用于航信项目832的AHU1～5，不能套用原功率专题两点／2分钟／7天合同。数据为历史采样统计，不产生控制建议或写现场参数。

## 2. 公开接口

- `QueryConditions(period, start, end, daily, start_time, end_time)`，`preference()`输出版本化非敏感偏好。
- `default_conditions(now=None)`、`restore_conditions(value, now=None)`、`resolve_query(conditions, now=None)`。
- `Query.windows`为按开始日期归属的半开`Window(day,start,end)`；`expected`为实际选中窗口的1分钟网格点数。
- `normalize(query, series, queried_at) -> Snapshot`；序列按point ID映射，记录为`{ts,val}`。
- `statistics(rows, running=False)`：全样本数／极值／线性P05P95／算术平均／温区桶。
- `load_ahu_temperature(query, *, progress=None, cancelled=None, ...) -> Snapshot`；只能在完整成功时返回。
- `export_snapshot(snapshot, kind)`，kind为`summary/daily/distribution/quality`；`export_notes(snapshot)`。

## 3. 数据与时间合同

设备12783～12787对应AHU1～5；每台airin／v20／v01分别是回风℃、反馈无量纲、频率hz。身份登记在领域的DEVICES／POINTS唯一维护，源校验项目、设备、point ID和单位；不得模糊按名字猜测。

默认近7个完整日、全天。UI日期两端包含，实际窗口左闭右开。跨午夜按开始日期归属，最后开始日的窗口延伸次日；未来校验使用最后真实结束时刻。不允许把起止相等当成24小时，全天使用开关。最多62个开始日期，未经实测不得静默放宽或改粗网格。

1分钟是请求网格，不保证是实际上报周期；三点精确同刻对齐，不插值、不前向填充、不按最近时间配对。反馈=1且0<频率≤60为开机；反馈=0且频率=0为停机；矛盾与未知独立。缺少状态不影响有效温度参与不限启停统计，但不得归入开机。

布尔值不是数值；有限真实0保留。重复同值去重、异值冲突使该字段失效。P05/P95采用排序位置`(n-1)*p`线性插值，总体分位数不得平均每日分位数，总体均值不得平均日均。界面舍入不影响计算。

质量分母仅包含实际每日窗口。连续缺测不能跨未选时段拼接；网格无值不是传感器故障诊断。温区分桶左闭右开，比例分母为该口径有效温度样本数，不叫精确持续时间。

源复用外部`AXIOMFORGE_XIAOMAI_ENV_FILE`及现有HTTPS认证，Token不落盘、不进入快照。每片至多24小时，取消标志在分片间检查；正在请求靠自身超时结束。不能发布部分成功的总体统计，不能将失败转换为空序列。

源边界须用冻结后的日期重新核对窗口与条件一致，不能信任调用方手动构造的Query；重新校验不得滚动相对日期，否则跨午夜启动的同一请求会改变范围。日期上限溢出需转为可显示的ValueError，不让日期控件触发未处理异常。

## 4. 校验与错误矩阵

| 输入／事件 | 结果 |
|---|---|
| 起止相同每日时段、逆序日期、超过62日、最后窗口在未来 | 本地拒绝，不能先登录 |
| 本月1日选择本月截至昨天 | 提示没有完整日，不默认为上月 |
| 坏缓存、类型／版本／项目错误 | 回退默认，不请求上游 |
| 测点身份、单位、响应结构不符 | 整次失败并脱敏 |
| 成功请求的空序列 | 正常无数据快照，保留五台与每日空行 |
| 任一网络片失败或主动停止 | 不发布新快照，旧结果由UI保留 |
| 运行字段缺失／矛盾 | 独立质量标记，不当成开机或停机 |

## 5. 基础、良好与错误场景

基础：查询昨天全天，比较五台不限启停与开机范围。

良好：10月1～3日22:00—次日06:00，最后结束10月4日06:00，共3×8小时；归属与导出一致。

错误：用10月4日00:00截掉最后窗口，或把每日18:00—次日14:00的未选时间算为连续缺测。

## 6. 必要验证

领域覆盖日／夜窗口、相等／未来／边界、偏好类型、空／单样本、冲突、非有限、开机状态、样本分母、分位数不可加及四类CSV元数据。来源测试使用假传输，覆盖认证／权限／身份、分段失败、取消与脱敏；自动测试不读取真实凭据。

原39日包离线核验五台全天及开机样本数、五项统计一致；业务日期时段以独立时间戳筛选复核。真实只读查询核验1分钟多点与长范围耗时，证据写任务research，不保存凭据或大量原始业务数据。

## 7. 错误与正确

错误：`mean(daily_means)`、`mean(daily_p95)`、`running_count / running_count`。

正确：用全部有效样本求平均和线性分位数；完整性分母来自查询窗口网格，温区分母来自有效温度样本，二者分开命名。

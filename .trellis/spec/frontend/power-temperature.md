# 航信真实功率与温度专题

## 1. 范围与触发

修改 `ui/power_temperature.py`、`ui/power_temperature_charts.py` 或航信专题路由、主题、项目切换前阅读。基础语义色和NiceGUI约定继续遵守 [工作台规范](nicegui-workbench.md)；数据定义遵守 [只读契约](../backend/power-temperature.md)。

## 2. 公开接口

- `PowerTemperatureView.build(dark: bool)`：挂载当前浏览器视图，不自动调用上游。
- `PowerTemperatureView.set_theme(dark: bool)`：更新当前图表颜色，保留输入、快照、选区和缩放。
- `PowerTemperatureView.deactivate()`：离开页面使挂载和请求代号失效。
- `trend_options(snapshot, dark, selection, focus, zoom, legend)`与`scatter_options(snapshot, dark, selection)`：创建新图表配置，不改全局模板。
- `refresh()`经 `run.io_bound` 调用只读源，配合90秒UI截止；不阻塞事件循环。

## 3. 状态与交互契约

Workbench按项目分派入口：仅航信显示功率与温度及航班专题分组，默认进入真实View；未选项目和其他项目隐藏专题分组。华师大／大润发默认进入项目概览，`data`显示待接入提示，`topic`／`flights`回退概览，不能从占位页按钮绕入航信专题。来源、环境及页脚必须说明真实只读；不复用演示样本、阈值参数、虚构运行记录或模拟成功提示。

筛选草稿与成功快照分离。快照的来源、范围、查询时刻不随输入改变；草稿变更显示待更新，失败显示错误并保留旧快照，二者都禁用导出。成功空数据必须替换旧结果，不能因为没有曲线而显示旧结果。

“缩放查看”只改视口；“选择分析时段”过滤摘要和散点，并明确所选范围。散点含唯一时间戳，点击后只定位趋势，不把分析选区缩成一个点。图例显隐不改变统计输入；重置选区恢复完整查询统计。

同一浏览器View拥有自己的loading、请求代号、快照和图表状态。离页或切项目使旧请求不能发布；关闭的容器不能继续渲染。取消项目切换不丢草稿，确认切换不将正在执行的请求重定向到另一项目。

全部时间标注现场时区；ECharts原生时间轴可能使用浏览器时区，因此formatter必须显式使用Asia/Shanghai。动态JS formatter遵循NiceGUI的冒号键约定，不把对象误作可求值的JS字符串。

## 4. 状态／错误矩阵

| 条件 | 展示与操作 |
|---|---|
| 初次进入 | 未查询提示，无伪造业务0值；只点查询才登录 |
| 未配置 | 提示服务端配置，不显示凭据路径或账号 |
| 加载中 | 保留旧快照，进度不定；防重复提交，导出禁用 |
| 草稿待更新 | 原结果范围与标签不变；提示刷新，导出禁用 |
| 上游失败／截止 | 错误脱敏，旧快照保留；不能伪装为空成功 |
| 全空／单边缺失 | 明确提示；单边有效曲线仍可看，配对与r不足时说明原因 |
| 切主题 | 不查询上游、不重建快照，保留缩放／选区／定位 |
| 离页后迟到响应 | 请求代号不符，不发布到新页面 |

## 5. 基础、良好与错误场景

基础：查询今天，核对四项摘要与明细，并导出完整快照。

良好：选中一小时，散点和摘要同步；点击一个散点定位时间；切暗色保留选区，重置后恢复全量统计。

错误：把ECharts缩放直接作为分析选区却不提示；CSV只导出图表当前可见点；切主题触发登录；未重新查询就把旧结果标为新日期。

## 6. 必要检查

领域／源自动测试之外，验证真实View的挂载、初始零请求、失败旧快照、请求代号、主题和CSV保护。1440×1024与1280×800亮／暗主题必须浏览器实测；用真实只读配置核对今天／昨天、明细分页、来源、选区、散点定位及导出。

回归项目概览、恢复最近项目、取消项目切换、其他项目无专题状态和今日航班。截图只证明布局，不代替事件交互或CSV核对；浏览器或下载被阻止时如实记录未验收项。

## 7. 错误与正确示例

错误：`snapshot.query = draft_query`；修改筛选时原地更改成功结果元数据。

正确：成功查询后整体替换不可变快照，`stale`由草稿与最近提交输入比较得到。

错误：调用过程结束后无条件 `render_results()`，离开页面后仍在已删除容器中写UI。

正确：请求完成先核对挂载与请求代号，再发布和渲染结果。

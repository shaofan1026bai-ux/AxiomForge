# AHU 回风温度页面合同

## 1. 范围与触发

修改`ui/ahu_temperature.py`、图表、独立CSS或工作台AHU路由时阅读。沿用NiceGUI和现有语义色，同时阅读[领域与来源合同](../backend/ahu-temperature.md)。

## 2. 公开接口

`AhuTemperatureView`提供`build(dark)`、`initialize_preferences()`、`set_theme(dark)`、`deactivate()`、`reconnect()`、`discard_draft()`及`dirty/loading`。工作台路由键`ahu-temperature`，仅`hangxin-airport`可进入。

初始化可在尚未挂载时恢复偏好，但不能调用历史数据源；挂载时同步表单。断开／离页使请求代号失效并停止后续片，重连仅恢复仍存活容器。主题只修改当前图表颜色。

## 3. 状态与交互

最近合法提交保存于`axiomforge.hangxin.ahu-return-temperature.query.v1`；仅保存日期规则／日期与时段，无原始温度、账号、Token或外部路径。恢复需调用唯一严格解码器；相对规则滚动、自定义固定。异步恢复不能覆盖用户已修改／提交的新草稿。

草稿与成功快照分开；修改条件不篡改旧图表标题。快照仅在整次成功且挂载／请求代号仍有效时发布。失败／停止保留旧快照且禁导出；成功空结果需替换旧结果，不能显示伪造0值。

五台对比表优先；默认开机区间图用细线极值、粗线P05P95、点均值，不冒充四分位箱线图。温区百分比显示有效采样分母。逐日保留空日，详情按业务起始日过滤，不改完整导出范围。图例、页签、排序、缩放和主题不取数。

详情中的真实序列必须显示独立有效点（`showSymbol/showAllSymbol`），同时保持`connectNulls=False`；实际每2分钟上报时1分钟网格隔点为空，隐藏符号会使所有线段消失。质量缺测段表在服务端切每页10行，分页控件`max-pages=7`，不能一次渲染跨月全部缺测段或全部页码。

日期时段开启后不限启停列不用“全天”标题；摘要显示每天时段、总窗口数及最后真实结束时刻，跨午夜必须标次日。恢复默认只改草稿，下一次明确提交才覆盖偏好。

进度来源于实际完成片数，停止等待不声称已中止上游SQL。工作台切项目确认应纳入AHU的dirty/loading，取消保留草稿与快照；确认后不发布迟到数据到新项目。所有已启用源的启动参数继续保留。

## 4. 状态矩阵

| 状态 | UI结果 |
|---|---|
| 首进／恢复偏好 | 显示条件，未查询，不自动取数 |
| 非法或未来窗口 | 行动提示，不保存为合法提交，不登录 |
| 草稿修改 | 上次结果范围保持，待更新提示，禁导出 |
| 加载中 | 真实分片进度，防重复提交，可停止，禁导出 |
| 停止／失败 | 上次结果保留且标明未更新 |
| 单台或全部成功空数据 | 保留五台行，空值有文字，不回退旧统计 |
| 坏缓存／存储异常 | 当前会话可查询，安全回默认 |
| 切主题／页签 | 当前输入、快照与查询次数不变 |

## 5. 基础、良好与错误场景

基础：查询全天，查看五台平均与主要范围。

良好：保存跨夜时段，刷新后恢复条件但无上游请求，手动查询后明细窗口与总体保持一致。

错误：用设计参考数据填充首次空态、用新草稿标题标记旧数据，或切换主题触发39日取数。

## 6. 必要验证

视图测试覆盖恢复零请求、类型错误、停止／迟到／失败旧快照、导出保护及独立客户端。浏览器核对每日开关、跨夜边界、恢复、图表交互、逐日详情、质量与CSV；1440×1024／1280×800亮暗主题。不能用HTTP200或截图代替查询、恢复与取消的交互验证。

## 7. 错误与正确

错误：存储键只叫`last_query`且跨项目共用，或将图表可见点导出为完整范围。

正确：使用项目＋专题＋版本的偏好键，导出完整成功快照；选择设备与查看日期仅定位详情。

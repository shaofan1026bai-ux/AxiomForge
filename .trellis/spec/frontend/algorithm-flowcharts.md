# 算法流程图页面契约

## 1. 范围与触发

修改算法与规则路由、`ui/algorithm_flowcharts.py`、`flowchart_canvas.py`及配套JS／CSS前阅读。[后端契约](../backend/algorithm-flowcharts.md)拥有版本、归属和SVG边界，[工作台约定](nicegui-workbench.md)拥有主题与项目导航。

## 2. View与画布接口

- `AlgorithmFlowchartsView.build(project_id, dark)`：按当前项目挂载。
- `set_theme(dark)`：同源码重绘，不改版本／草稿，保留缩放、视口与节点选择。
- `confirm_leave() -> bool`：未保存时确认；取消、保存失败或冲突时返回False。
- `deactivate()`／`reconnect()`：挂载与迟到响应保护。
- 画布事件须携带请求代号与源码指纹；元数据只从成功渲染的当前图获得，不把临时SVG DOM ID当稳定业务节点ID。

## 3. 交互契约

草稿、有效预览和保存版本独立。源码变更后旧图继续显示但标为预览过期；语法错误不覆盖旧图。保存必须对应当前源码成功预览，导出必须对应当前已保存且有效的版本，不能把旧图贴上新源码／版本标签。

目录按项目隔离；只有航信自带AHU样例。华师大、大润发初始为空，可新建自己的图，不共享航信算法。界面写“图示版本”，不宣称与可执行算法或现场配置同步。

切图／版本／模块／项目若有草稿需保护；与工作台既有项目确认整合，不连续弹两次确认。取消保持原上下文，保存失败不继续导航。刷新只恢复保存版本，不能把浏览器临时状态当持久化。

画布缩放与平移不写源码。导出完整SVG，不裁切视口；T／C保留黄色及文字“可配置”标识，实际参数待关联，不虚构温度或时段。

不直接使用原生ui.mermaid的失败覆盖行为。渲染先在暂存区域完成检查，成功原子替换；同页面排队、唯一ID、严格模式、纯SVG文字，禁止用户控制全局初始化或执行点击脚本。输入限制与渲染上限一起防阻塞；不能仅靠setTimeout声称可以中断同步布局。

## 4. 状态矩阵

| 状态 | 展示及操作 |
|---|---|
| 当前项目无图 | 本项目空目录，可新增，不加载其他项目种子 |
| 草稿未预览／预览中 | 旧图有来源提示，不能保存新稿或导出旧稿冒充 |
| 语法失败 | 错误提示、旧图保留、草稿可继续编辑 |
| 预览成功但未保存 | 可保存，不能导出为已保存版本 |
| 历史版本 | 明确历史标识，通过以此版本编辑派生，不改写原版本 |
| 保存冲突／失败 | 保留草稿及选择，不自动导航 |
| 切主题 | 保留源码、版本、视口和节点；旧主题迟到渲染不能覆盖新主题 |

## 5. 基础、良好与错误场景

基础：查看航信样例，点击T与B看到不同条件／设备范围。

良好：编辑后语法失败，仍可看原有效图；修正后保存新版本，刷新仍存在，导出的SVG可离线打开。

错误：只检查曾经预览过就允许保存后来改过的源码；切项目后使用上个项目SVG／节点详情；放宽securityLevel来启用源码里的click脚本。

## 6. 必要检查

1440×1024、1280×800亮暗主题、中文节点、缩放／平移／适应／全屏及节点详情。验证失败保留旧图、存储冲突、切换取消、迟到事件、版本恢复、SVG整图下载与离线检查。回归现有四个真实专题和统一启动配置。截图不代替交互、保存重启或SVG文件验证。

## 7. 错误与正确示例

错误：`preview_ok=True`全局布尔值，任何新草稿都可继续使用这个状态。

正确：保存前比较`preview_source_hash == source_hash(draft.source)`，并核对当前项目、图ID与有效请求代号。

## 本轮状态问题与防回归

- 放弃草稿须清除历史派生标记，并将有效预览恢复到保存源码，不能在再次进入时复活被放弃的源码。
- 保存结果按项目、图ID和文档内容上下文接收；主题重绘增加渲染代号不能丢弃已成功写库的版本。
- 节点事件也必须携带有效预览代号；仅比较源码指纹无法区分源码相同的不同文档。
- 对相同dirty值不重复发送组件更新，渲染请求按代号去重，避免深层属性监听形成渲染循环。
- 合法Mermaid静态滤镜包括feDropShadow；两端SVG白名单同步维护。清除CSS动画属性时同时处理末尾无分号情况。

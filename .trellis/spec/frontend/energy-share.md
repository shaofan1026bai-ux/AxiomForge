# 每日用电占比页面合同

## 1. 范围／触发

修改`ui/energy_share.py`、图表及独立样式前阅读。航信专属路由`daily-energy-share`，与其他专题共享工作台和主题，拥有独立客户端草稿／快照。

## 2. 签名

`EnergyShareView`对工作台提供`build(dark)`、`set_theme(dark)`、`deactivate()`、`reconnect()`、`discard_draft()`、`dirty/loading`、异步`initialize_preferences()`。领域与源来自独立energy_share模块，不复用演示数据或AHU温度类型。

## 3. 状态与图形合同

初进与恢复均不取数。偏好键`axiomforge.hangxin.daily-energy-share.query.v1`仅存最近合法提交条件，相对日期重开滚动，自定义保持。恢复不能覆盖用户新草稿。源I/O在线程执行，所有UI变化回主循环；每次提交请求代号、取消事件和mounted校验共同防止迟到发布。

三个页签：每日占比、区间汇总、读数与质量。固定八项颜色／顺序，图例只高亮，不删除系列和重算分母。缺测日期保留坐标，%为空并提示不可确定；kWh仅显示已知小计，未知不用0填充。日期选择可键盘访问，图点击同样同步明细。选中日不影响完整导出。

失败／取消保留旧快照，加载／失败／停止／待更新时禁导出。主题不取数；离页／断开使请求失效；切项目确认包含dirty/loading。区间双口径独立展示覆盖范围，不用较完整结果掩盖另一口径。

## 4. 验证与错误矩阵

| 事件 | 行为 |
|---|---|
| 恢复偏好 | 不自动认证或取数 |
| 草稿变化 | 旧快照保留原范围，禁导出 |
| 停止／离页／断开 | 无迟到结果发布 |
| 任一组缺测 | 所有8项占比为—，已知电量保留 |
| 图例高亮 | 所有系列仍在，分母不变 |
| 切主题 | 只改颜色，数据快照保持 |
| 无有效完整日 | 展示缺测，不跳出查询范围 |

## 5. 好／基本／坏案例

基本：查询后选择某天查看八行表。好：10月27日缺失AHU总表，七项小计1655.15可见，八行share均为—。坏：显示七项“100%”，或以缓存恢复触发现场查询。

## 6. 必须验证

自动验证偏好竞态、失败／取消导出门禁、迟到请求、图形缺值／零值与固定分母。浏览器验证1440×1024／1280×800亮暗主题、模式切换、日选择、质量明细、双区间、停止和完整CSV；截图不能替代交互验证。

## 7. 错误与正确

错误：通用100%图例点击时删除系列并重归一化。正确：所有8项始终保留，仅调整所选项的视觉强调，百分比来自领域快照。

图表`datazoom`视口保存在当前View内，新查询或显式切换7／14／31日才重置；选日、模式和高亮保留用户视口。缺失日界也展示已有两侧或单侧支撑，不能把展示证据误作允许插值。

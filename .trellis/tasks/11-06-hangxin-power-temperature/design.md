# 航信功率与温度分析专题：详细设计

状态：2026-11-06 用户批准详细方案，进入实现。

## 1. 页面与入口

- 复用现有“航信机场 → 功率与温度分析”专题入口，航信项目的“数据分析”也进入同一真实分析视图，不复制第二份结果。
- 页标题为“功率与温度分析”，副标题为“芒市机场 · 1#空调机组”，环境标识改为“小麦只读”；来源面板完整保留两台设备的原名，不将两台来源设备伪装为同一设备。
- 航信项目进入本页时只渲染查询表单与未查询提示；首次不自动登录、查询或生成演示数据。根据2026-11-06用户追加要求，其他项目隐藏整个专题分组并默认进入项目概览；共享数据分析显示待接入状态，直接或间接访问航信专题均回退概览。今日航班仍仅属于航信。
- 使用既有 Research Canvas 的间距、边框、字重与语义色，不另建站点、登录页面或前端框架。

## 2. 信息结构

| 顺序 | 区域 | 信息与交互 |
|---|---|---|
| 1 | 页标题与来源提示 | 项目、分析对象、小麦只读、查询完成时间；“查看来源”切换到来源页签 |
| 2 | 页签 | 分析结果、数据明细、测点与口径；切换只读本地快照，不调用上游 |
| 3 | 共用查询栏 | 今天／昨天／自定义、起止日期时间、查询刷新、导出CSV；显示 Asia/Shanghai 和上游2分钟采样 |
| 4 | 统计摘要 | 平均功率、最大功率及发生时间、室外温度范围、有效配对数／期望数；均注明当前分析范围 |
| 5 | 功率与温度趋势 | 功率左轴kW、温度右轴℃，功率实线、温度虚线；共用时间提示、缩放与选区 |
| 6 | 功率—温度关系 | 温度横轴、功率纵轴，相关系数、样本数、选中范围与重置；每个散点绑定唯一时间戳 |
| 7 | 状态与质量说明 | 各序列缺失数、异常／重复时间处理、最后有效数据时间；来源与聚合含义尚未确认的说明 |

1440×1024 时趋势与散点采用约2∶1的双栏，统计卡四列；1280×800 时两图上下排列，统计卡可变为两列，查询栏自然换行。允许页面纵向滚动，避免横向滚动和压缩坐标标注。图表高度约340–380px；来源长ID放在可复制的来源表内，不占主图标题空间。

## 3. 查询与快照

### 3.1 时间范围

- 今天：上海时区当天00:00到点击查询时的当前分钟；昨天：昨天00:00到今天00:00。
- 自定义：起止精确到分钟，使用左闭右开区间 `[start, end)`；开始必须早于结束，结束不得晚于当前分钟，最大跨度7×24小时。
- 上游查询间隔固定为已经验证的2分钟，首版不提供未经验证的聚合间隔开关。保留上游点值，不宣称它是瞬时原始值或区间平均值。
- API时间字符串无时区，首版按现场时间解释为 Asia/Shanghai，并在来源说明中注明该解释；不混入系统执行主机时区。
- 用户任意分钟起点作为该次查询的2分钟网格起点；按最长24小时连续切片时维持同一网格起点，不按日历日重新错位。每片最多720个期望时间点。
- 发送上游的结束边界可能包含最后点，归一化后仅保留 `[start, end)`；切片重合时间去重，不能重复计入统计。

### 3.2 数据与草稿状态

视图保存 `draft_query`、`snapshot`、`selection`、`loading`、`error` 和请求代号。快照包含实际提交范围、取数时刻、来源映射和完整数据，不随着表单文字变化而改变。

| 状态 | 页面行为 |
|---|---|
| 未配置／未查询 | 清楚提示配置或点击查询，不显示0值业务卡或伪造图表 |
| 加载中 | 保留原快照，显示不确定进度，禁用重复提交与导出 |
| 成功有数据 | 整体替换快照，清空旧选区，显示真实范围与查询时间 |
| 成功空结果 | 展示本次查询的空快照，明确两序列均无数据；不保留上次曲线假装成功 |
| 仅一序列有数据 | 展示可用曲线及对应摘要，散点为空，提示另一序列缺失 |
| 筛选已修改 | 旧标题、图表与来源仍属于原快照；显示“筛选已修改，请查询刷新”，禁用导出 |
| 请求失败 | 保留旧快照并显示失败／旧快照标识，导出禁用直到下一次成功查询 |
| 离开页面／切换项目 | 不把已发请求改成新项目；请求完成仅在请求代号与页面挂载有效时发布结果 |

表单改变使结果待更新；主题、页签、框选、点击定位不使结果待更新。浏览器刷新后清空分析快照，继续沿用现有主题与项目偏好持久化。

## 4. 两图联动

- 趋势的工具栏区分“缩放查看”与“选择分析时段”。缩放仅改视口；选区同时更新散点、统计摘要与质量提示，并显示明确的选中范围。
- 选区采用时间范围，不从 ECharts 的采样索引猜测时间。所有分析选择由完整快照过滤得出；“重置选区”恢复全量。
- 散点只展示同一时间戳两个有限数值均存在的样本。悬停显示时间、温度、功率；相同坐标可重叠，但不去重时间样本。
- 点击散点只在趋势上定位、加标记并使该时间可见，不将分析选区缩到一个点，不触发再次查询。重置选区不删除快照。
- 图例开关只影响曲线显隐，不删除数据或改变统计；每条曲线使用颜色加线型区分。
- 温度轴随有效数据留白调整，不沿用演示页固定0–35℃的范围。功率与温度双轴均显示单位，不将线条重合解释为相关性。
- 主题切换只更新当前客户端图表色彩，保留视口、选区、定位和草稿，不重算或请求数据。

## 5. 统计与质量口径

| 项目 | 定义 |
|---|---|
| 期望点数N | 当前分析范围内，从本次查询起点以2分钟步进的时间网格点数；不含结束边界或未来点 |
| 平均功率 | 范围内所有有效功率样本的算术平均；不要求温度同时有效，不称为时长加权均值 |
| 最大功率 | 范围内有效功率最大值，多个并列值显示首次发生时间 |
| 温度范围 | 范围内有效室外温度的最小值与最大值，与功率缺失独立 |
| 有效配对比例 | 同一网格时间两个值均为有限数值的样本数n除以N，同时显示n／N；不使用仅有返回值的交集作为分母 |
| Pearson r | 在当前范围的n个有效配对上计算；n<3或任一序列方差为0时显示“不可计算”及具体原因，不返回0冒充弱相关 |

质量规则：

1. `null`、缺少记录、空字符串及非有限数值均按缺失／无效分别计数；真实0保留。布尔值不作为数值接受；负值不擅自置零。
2. 不做插值、前向填充、平滑、异常温度截断或温度时间偏移；缺失时间使用空值绘制断点。
3. 时间排序、解释为现场时区并去重；相同时间相同值保留一份，相同时间不同值标记冲突、该时间该序列无效，不选择更有利于相关性的值。
4. 响应中越界点计数后丢弃；非法时间或不在请求网格的时间计入异常说明，不做最近时间强行配对。如果响应整段时间结构不兼容，则作为协议错误，不能显示为成功空数据。
5. 响应测点 ID、项目、设备和单位必须与登记映射相符；不能按响应数组顺序判断功率和温度。字段缺失或不符按接口错误处理，禁止跨项目混用。
6. “数据质量”仅表示本页对完整性与可解析性的检查，不等于传感器精度或上游故障判定。样本窄温差、缺失多等情况如实提示，不自动产出节能结论。

## 6. 明细、导出与来源

- 明细按统一时间网格列出时间、功率、室外温度和状态；默认每页50行，可选择只看当前分析选区，页头明确行数口径。
- CSV固定导出完整成功快照，按钮说明“完整查询范围”，不因图表缩放或选区而静默删行；记录开始／结束、查询时间、时区、上游间隔、来源、项目、设备及测点ID、单位、数据质量字段。
- 缺失数值导出空单元格并提供状态，不输出字符串0替代。采用UTF-8 BOM，延续项目现有CSV兼容方式。
- 来源页签显示经用户指定的映射、只读说明、现场时间解释、上游2分钟值的聚合含义待确认、当前样本覆盖与本地统计公式。凭据路径、密码、Token不进入前端。
- 不复用演示页的“应用参数并分析”、虚构算法版本、模拟运行记录或示例功率阈值。首版没有可编辑控制参数或代码执行入口。

## 7. 数据与认证架构

### 7.1 模块边界（拟新增）

- `src/axiomforge/power_temperature.py`：固定映射、查询范围、测点序列、快照、网格归一化、统计、选区与CSV；纯Python，不连接上游。
- `src/axiomforge/xiaomai_source.py`：服务端外部配置、RSA登录、项目权限和测点归属检查、两点批量历史读取、脱敏错误；只允许固定只读路径。
- `src/axiomforge/ui/power_temperature.py`：每浏览器 `PowerTemperatureView`，负责筛选、异步查询、页签、联动和主题。
- `src/axiomforge/ui/power_temperature_charts.py`：本专题ECharts配置，复用现有 `charts.palette()`，不把演示 `Sample` 当成真实数据模型。
- `main.py` 增加 `--xiaomai-env-file` 与 `AXIOMFORGE_XIAOMAI_ENV_FILE` 入口；`workbench.py` 按航信项目分派真实视图及环境标签。

不为此引入独立HTTP服务、SQLite、React或新的应用登录会话系统。

### 7.2 来源登记

| 字段 | 固定值 |
|---|---|
| 工作台项目 | hangxin-airport |
| 上游项目 | 832（芒市机场） |
| 上游域名 | https://smart-energy.yntravelsky.net.cn:36443 |
| 功率设备／测点 | 12744 / wh171k_mspm03_totalpower，kW |
| 温度设备／测点 | 12788 / nfdh9q_mscrk01_c21，℃ |

两台设备独立保存来源；由这组业务映射配对，不以相同设备ID或名称子串推测关联。

### 7.3 每次手动查询的调用顺序

1. 服务端读取外部配置，验证域名与固定航信项目；RSA/PKCS#1 v1.5 + Base64加密原始密码，提交 `UserLogin`。
2. 校验业务成功与用户／公司信息，从响应头 `Access-Token` 取用户凭据；之后使用 `Authorization: Bearer <token>`。
3. 查询 `GetUserOwnProject` 并确认包含项目832。公司身份取登录结果，不以配置中的公司ID替代。
4. 批量查询设备12744、12788的激活测点，验证完整映射与单位。
5. 两个测点在同一请求中查询历史；最多24小时一段，按时间顺序读取，最长7段。全部分段成功后形成一个不可变快照，不把部分请求成功当成全区间成功。
6. 取数后丢弃Token。每次明确的手动刷新重新登录，不缓存Token、不猜测有效期，也不自动循环重试。

I/O通过 NiceGUI `run.io_bound` 移出事件循环。请求绑定提交时的范围与项目，快照不保存网络响应头、原始登录响应或凭据。

### 7.4 配置与依赖

- 配置使用现有 `python-dotenv`，`interpolate=False`，文件外置；未显式指定配置时提示未配置，不从桌面历史文档或压缩包读取密码。
- 使用已有 `XIAOMAI_ACCOUNT`、`XIAOMAI_PASSWORD`、`XIAOMAI_LOGIN_URL`，公开RSA公钥从参考包固定为应用默认，允许 `XIAOMAI_PUBLIC_KEY` 覆盖以支持轮换。
- 拟新增明确的直接依赖 `httpx`、`cryptography`、`truststore`，实际兼容版本在实现时锁定。RSA走Python库而非浏览器JS或shell；HTTP使用系统证书信任的SSL上下文，保持TLS验证。
- 禁止携带凭据跨源重定向，不允许URL内嵌账号。仅允许航信域名及36443端口；特殊测试源通过可注入测试传输验证，不改变生产目标限制。
- 单次HTTP请求超时15秒，整次查询截止90秒；不显示伪百分比。截止时结果失败且旧快照保留，迟到响应不发布。
- 捕获错误后显示配置、认证、权限、网络、历史结构等可行动的脱敏类别；不向UI或普通日志透传上游完整异常或正文。

## 8. 兼容、部署与回滚

- 外部配置入口独立于航班SurrealDB配置，两个专题互不替换数据源。
- 工作台项目选择、其他项目概览及待接入状态、今日航班保留。取消项目切换时不丢失本页快照或草稿。
- 请求代号与页面挂载标识使离开页面后的结果安全失效；回到页面可查看原成功快照并手动再查。
- 回滚以移除真实专题路由和新增数据源入口为界；不改现场、不建表、不涉及命令补偿。
- 当前工作区已有其他未提交工作，实现只改本任务涉及区块，提交前核对差异，避免覆盖或混入无关改动。

## 9. 风险与明确推迟项

- 上游`interval`背后的聚合函数、采集质量与现场时区官方说明未齐备；本页说明实际使用口径，不做能耗积分或预测模型。
- 已有2小时两点同时间戳查询证据；另已成功核验今天及过去6个完整日的分段历史，结果写入研究记录。日期范围支持以实查与异常处理测试共同验收。
- 特殊传感器故障码尚无字典，不自动剔除任意极端值；通过明细可复核。若目标点实查出现明确故障码，先补契约再实现过滤。
- 相关性受运行策略、负荷与时间因素影响；不输出温度影响百分比、因果结论或可停机时段。
- 长期保存、其他机组选择、天气回退与自动任务留给后续独立需求。

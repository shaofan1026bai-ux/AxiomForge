# 航信功率与温度分析专题

## 目标与用户价值

在现有 NiceGUI 工作台中，为航信机场提供真实数据的功率与室外温度分析，帮助用户查看功率随温度和时间的变化，并定位值得进一步查看的时段。

## 已确认背景

- 2026-11-06 用户同意建立专题任务并进入详细设计，已明确批准最新详细方案并要求开始实现。
- 用户指定功率来源为“1#空调机组电表—总有功功率”，温度来源为“1#空调冷水机组—室外温度”。点位及登录环境已经只读实查，映射以 `docs/interfaces/projects/hangxin-airport/connections.md` 为准。
- 沿用 Research Canvas、项目切换和亮／暗／系统主题，不引入另一套前端。
- 已确认首版包括时间查询、统计摘要、趋势、散点相关性、数据明细、CSV 导出及两图定位交互。

## 需求

| ID | 需求 |
|---|---|
| R1 | 仅航信项目使用已验证的真实测点；页面清楚展示项目、两台来源设备、测点、单位及只读状态。 |
| R2 | 默认今天截至查询时刻，支持昨天、自定义日期时间与手动查询；入口不自动登录或轮询。首版范围最多连续7天，已核验近7个日历日的分段历史，其他时间的缺失与异常仍需明确处理。 |
| R3 | 展示所选时段平均／最大功率、室外温度范围和有效配对比例，明确统计区间与查询时间。 |
| R4 | 双轴趋势使用功率实线、温度虚线；可缩放并同时查看同一时间的值。框选后以明确的“选中时段”标记联动散点与摘要，可重置到完整查询范围。 |
| R5 | 散点横轴室外温度、纵轴功率，显示有效配对样本数与 Pearson 相关系数；点击散点定位趋势中的对应时间。相关系数不解释为因果、预测效果或节能空间。 |
| R6 | 明细分页显示时间、功率、室外温度和数据状态；CSV 包含完整查询快照、有效性说明与来源元数据，不随图表缩放隐式删减。 |
| R7 | 缺失保留断点，只用有效时间配对计算散点；真实0与缺失区分。空结果、单序列缺失、请求失败及结果待更新均有明确呈现。 |
| R8 | 只读凭据来自仓库外部配置；密码和 Token 不进入浏览器、源码查看、运行记录、导出及普通日志。 |
| R9 | 保留现有航班专题和项目偏好；功率与温度仅属于航信，华师大／大润发隐藏专题并默认进入项目概览，其数据分析显示待接入；切换主题不查询上游，不重置图表选择、结果或输入。 |
| R10 | 筛选草稿与结果快照隔离，旧结果保持旧标题和范围。加载期间防重复请求；切换页面或项目后迟到响应不得污染当前画面。 |

## 验收标准

- AC1（R1、R8）：航信专题使用用户指定的两条测点；核对项目与单位，未配置或认证失败时不显示模拟成功数据或敏感内容。
- AC2（R2、R10）：今天／昨天／自定义时间可查询；未来、反向和超过7天范围在本地拦截；有效今日范围只查询至提交时刻，修改输入后标记旧结果待更新。
- AC3（R3、R7）：统计值可由样例快照复算；显示配对分子与分母，不把未来时间或缺失计为零值，区分所选区间与最后数据时间。
- AC4（R4、R5）：趋势、框选散点与摘要联动；点击散点定位时间但不递归改写选择范围；重置恢复全量；样本不足或任一序列恒定时相关系数为“不可计算”。
- AC5（R6、R7）：明细与导出均可核对来源、时区和缺失；CSV 导出完整已查询范围，筛选草稿未应用时禁用导出。
- AC6（R7、R10）：覆盖全空、单测点无数据、部分空值、异常结构、重复／无效时间、请求失败和离开页面时完成的响应；失败保留上次成功快照并明确失败状态。
- AC7（R8）：上游 Token 只在服务端短期内存中使用；不跨域重定向携带凭据，TLS 校验开启，登录／历史错误脱敏。
- AC8（R9、R10）：1440×1024、1280×800 的亮暗主题可用；项目、浏览器间状态互不污染；今日航班回归通过；华师大和大润发不出现航信专题，数据分析不绕入功率与温度页。
- AC9（R2）：已有今日、昨天及近7个日历日的分段查询证据；实现时仍需验证归一化和切片不丢失／重复时间点，不静默截断结果。

## 不在首版范围

多机组配置界面、天气替代源、自动刷新、模型训练或预测、温度滞后分析、自动异常归因、节能量计算、设备控制、定时调度及持久化历史数据库。

# 算法流程图模块设计

## 目标

用户在现有“算法与规则”中，将某个项目算法的Mermaid文本转成专业、可浏览和导出的流程图；图示可以编辑、保存和查看版本，方便理解与沟通逻辑。

## 已确认背景

- 2026-11-09用户提供航信AHU决策流程，随后同意“Mermaid编辑、流程图展示、保存及SVG导出”的首版范围，并同意创建任务进入详细设计。
- 入口使用现有“算法与规则”，算法目录按项目隔离；首条样例仅属于航信。沿用Research Canvas及亮／暗／系统主题。
- 保留样例的原始判断、动作、是／否分支和T／C的configurable标识，不修改业务逻辑。

## 需求

| ID | 需求 |
|---|---|
| R1 | 当前项目独立的流程图目录，航信提供AHU运行策略样例；其他项目显示本项目空目录，不展示航信图。 |
| R2 | 支持新增图示、填写名称及说明、粘贴或修改Mermaid源码，区分编辑草稿、有效预览和已保存版本。 |
| R3 | 画布自动布局，支持缩放、拖动画布、适应窗口和全屏；中文节点与是／否分支可读。 |
| R4 | 判断与动作节点形状清晰，T／C使用黄色和“可配置”文字标识；点击节点查看信息，不把全局关闭与局部关闭混淆。 |
| R5 | 语法错误时显示可理解的错误并保留上次有效图，不将错误草稿冒充有效版本保存或导出。 |
| R6 | 显式保存形成新的不可变图示版本，记录名称、说明、源码及节点注释；刷新和重启仍可找回，可浏览旧版本并以其为起点编辑。 |
| R7 | 导出所选已保存版本的SVG，包含名称和图示版本，文件可离线打开；未保存改动不被悄悄忽略。 |
| R8 | 切算法、版本、项目或离开模块时保护未保存草稿；迟到预览不能覆盖新选择，多个浏览器并发保存不能静默覆盖。 |
| R9 | 图示用于逻辑说明，版本明确为“图示版本”，不宣称已绑定可执行代码或现场参数；不执行链接、脚本、任务或控制。 |
| R10 | 兼容现有航班、功率温度、AHU回风温度和每日用电占比专题；主题变化不修改源码或逻辑。 |

## 验收标准

- AC1（R1、R4）：航信样例包含T、N、A、B、C、E、F、G、H九个原始节点及全部原始连线，T、C高亮；N与B分别说明全局／对应AHU范围。其他项目无此样例。
- AC2（R2、R5）：合法源码可预览；错误草稿有提示且旧图保留，清楚标明旧预览，保存／导出不得冒用它代表新草稿。
- AC3（R3、R10）：1440×1024、1280×800亮暗主题下验证缩放、平移、适应和全屏，长中文不截断，分支清晰。
- AC4（R6、R7）：保存后刷新／重启能打开相同内容，旧版本不改写；导出SVG内容及元数据与所选已保存版本一致。
- AC5（R8）：未保存草稿切换时可以取消、放弃或保存合法草稿再切换；取消不改变当前上下文；并发更新旧基线时提示冲突。
- AC6（R9）：节点说明标注参数待关联，不虚构设定值、执行状态或代码版本；不支持的图类型、链接和配置指令不会执行或污染其他图。
- AC7（R10）：原有项目导航、分析专题及两数据源启动配置不退化；流程图编辑与渲染不查询现场系统。

## 不在首版范围

拖拽节点改逻辑、任意Python自动精确转图、运行参数编辑、控制执行、实时路径高亮、定时调度、PNG／PDF导出、跨项目复制、删除版本及其他Mermaid图类型。

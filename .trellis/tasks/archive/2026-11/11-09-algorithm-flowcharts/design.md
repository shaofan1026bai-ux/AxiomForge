# 算法流程图模块：详细设计

状态：2026-11-09用户已批准本详细方案并要求开始实现。

## 1. 入口与布局

使用现有侧栏“算法与规则”，内部替换占位状态，不新增同名项目专题。当前项目始终可见，切项目加载该项目目录。

| 区域 | 内容 |
|---|---|
| 顶栏 | 图示名称、说明、图示版本、已保存／未保存状态；新增流程图、保存新版本、导出SVG |
| 算法目录 | 当前项目名称列表与版本选择，航信首条“AHU运行策略”；其他项目为空，可新增自己的图 |
| 主画布 | 自动布局的流程图，缩小／放大、百分比、适应窗口、全屏；背景适度网格或纯色，节点不使用截图 |
| 编辑页签 | “流程图”“Mermaid源码”；源码页可分栏预览，提供“更新预览”和错误提示，不逐个按键渲染 |
| 节点详情 | 点击节点后显示节点ID、文本、类型／可配置标识、业务说明；无选择时显示图例与使用提示 |

1440宽度时目录约200px，详情约260px，主画布占剩余空间。1280宽度时详情改为可收起抽屉，避免三个固定窄栏挤压中文。保留现有工作台侧栏和页头；全屏只放大画布区域，退出后恢复原位置与缩放。

首版不加载现场接口，不显示“算法运行中”或实时命中路径。版本字段明确写“图示版本”，关联可执行算法的字段暂不开放。

## 2. 样例与视觉规则

原始文本保存在`research/hangxin-ahu.mmd`，实现时复制为应用自带种子资源，不在运行时依赖任务目录。

- 首个样例标题“AHU运行策略”，说明为“夜间、人员／航班保障与预冷、回风温度及冷水机组条件下的AHU／新风阀决策说明”。
- T、A、C、F保留判断菱形，N、B、E、G、H保留动作形状。首版不提供拖拽节点或连线编辑器。
- T、C的configurable样式保留用户给定黄色与文字色；详情增加“可配置条件”文字，不能只靠颜色。其余节点随工作台主题使用清楚边框与对比色。
- 样例注释仅说明T为夜间时间条件、C为温度设定条件，具体时间段和设定温度均“待关联”，不自动填22:00或26℃等值。
- N描述“所有AHU及新风阀”，B描述“对应AHU及新风阀”；图示尚未绑定具体设备清单，不能声称已能下发。
- 不重命名节点ID、不修改分支和阈值运算符。自定义classDef限制为节点的颜色、边框与基础文本属性；样例样式应原样兼容。
- 原始源码作为权威逻辑；查看方向由源码的TD／LR等声明决定，缩放和拖画布不写回逻辑。

## 3. 编辑、预览与切换

维护三种独立状态：`draft`（名称／说明／源码）、`valid_preview`（内容指纹与有效SVG）、`saved_revision`（存储中不可变版本）。

1. 选择算法与版本，加载已保存内容，渲染时显示加载状态；成功后适应画布。
2. 修改任意可保存字段即标为未保存。源码修改后显示“预览尚未更新”，保留旧图并注明它来自上次有效源码。
3. 点击“更新预览”按当前源码渲染。成功后更新有效图；失败只更新错误区，不覆盖旧图，不用旧图伪装新草稿。
4. 保存名称／说明变更时，源码必须已有相同内容指纹的有效预览。预览未完成或失败时保存按钮禁用，提供更新预览提示。
5. 保存创建新版本，不原地覆盖旧版。重复保存无变更内容不制造空版本。保存成功更新目录与版本，但不自动切到其他图。
6. 切算法、版本、项目或离开模块，若有未保存内容则提供“取消”“放弃改动”“保存并继续”；最后一项仅合法预览可用。保存失败或冲突不得继续切换。
7. 历史版标注“历史版本”；可以“以此版本编辑”创建新草稿，其保存仍接到当前最新版本之后，并记录派生来源，不改变原历史版。
8. 浏览器刷新保留已保存版本；未保存草稿首版不自动落盘。可在支持的页面关闭流程中提示未保存，不能承诺浏览器崩溃后恢复。

每次渲染带请求代号、项目、图ID、源码指纹与主题。切换或更新使旧请求失效，旧图的迟到结果不得发布到新选择；SVG、节点详情和导出也不能串项目。

## 4. 画布与节点交互

- 缩放范围建议25%–200%，支持按钮和以鼠标位置为中心的滚轮缩放；拖动空白区域平移，不改变节点相对坐标。
- 适应窗口基于SVG viewBox与容器尺寸，保留内边距，长竖图允许放大后平移查看，不把所有文字缩成不可读小点。
- 点击节点高亮当前选择、打开详情；仅由应用绑定本地节点事件，不执行Mermaid的click/link脚本。
- 节点基础文本与configurable类来自成功渲染结果；补充业务注释以节点ID维护。源码删除或重命名节点后，孤立注释标为待核对，不绑定到其他同名节点。
- 主题切换重新渲染同一份源码并保持视口中心、缩放与选择；不修改草稿、版本或保存时间。工作台主题为默认样式，用户显式classDef样式保留。
- 全屏通过标准浏览器能力实现，提供清楚的退出入口及Escape；不可用时提示并保留正常画布。

## 5. 渲染边界与SVG导出

本地NiceGUI已包含Mermaid，无需CDN或独立React应用。原生组件遇错误会替换为错误图，且初始化使用模块级Mermaid对象，因此不能直接依赖它实现“失败保留旧图”和多图配置隔离。

拟增加小型自定义NiceGUI画布组件，复用随包Mermaid引擎：

- 显式点击预览后调用解析／渲染；先在非展示容器生成、检查，成功后原子替换当前SVG。失败展示结构化错误并清理暂存容器。
- 同一页面渲染排队，每次使用应用控制的主题与渲染设置及唯一SVG ID，不能让用户源码切换全局配置。
- 使用严格渲染模式和纯SVG文本标签；首版只支持flowchart／graph。禁止用户脚本、链接／click指令、初始化指令、外部图片、HTML及自定义配置前言，保留一般注释、节点、边、subgraph和受限样式。
- 两端校验输入大小与类型，建议源码上限64KiB；浏览器解析检查节点／边数量及渲染超时，超限拒绝预览，不长期阻塞页面。实施时以现有样例与边界测试确认限额，不把上限当厂商保证。
- SVG在展示和导出前检查：无脚本、事件属性、外链、foreignObject或活动内容，ID不与其他图冲突；输入校验不能只靠字符串查找取代SVG检查。

导出按钮仅对当前有效的已保存版本可用。有草稿时要求先保存或切回已保存版本，不暗中导出旧版。导出文件名由应用生成，包含名称与图示版本；SVG含可访问标题与说明，明确项目和版本。导出的范围是整张图，包含完整viewBox，不受用户缩放／平移裁切。首版按当前主题导出，不增加额外主题选项。

## 6. 持久化与版本契约

使用本机SQLite保存元数据与源码，路径默认`.nicegui/algorithm-flowcharts.sqlite3`，沿用已忽略的本地运行目录；不把用户编辑内容写进源码或任务PRD。Python标准库即可，不引入数据库服务。数据库文件不保存设备凭据、Token或实际运行数据。

拟新增记录：

- `flowcharts`：`id`（随机UUID）、`project_id`、`created_at`、`latest_revision`。
- `flowchart_revisions`：`flowchart_id`、`revision`、`name`、`description`、`source`、`annotations_json`、`content_hash`、`created_at`、`derived_from_revision`，联合主键`(flowchart_id, revision)`。
- 元数据保存模式版本，初始化建表用事务；不修改其他专题的存储。

查询和写入都必须携带工作台项目ID并验证归属，不靠前端过滤目录防串项目。保存使用事务和预期`latest_revision`做乐观并发检查；若其他浏览器已更新，保持当前草稿并提示重新加载最新版本，不静默覆盖。

首个航信样例作为种子，仅首次初始化或尚无该种子记录时插入v1；刷新、重启和升级不能重复插入或覆盖用户版本。普通新建流程图不自动复制航信样例到其他项目。首版没有删除和跨项目移动，降低不可恢复操作与映射复杂度。

## 7. 代码边界与集成

拟新增模块，具体函数签名在实现时按测试保持一致：

| 模块 | 职责 |
|---|---|
| `algorithm_flowcharts.py` | 项目／图示／版本记录、源码基本限制、指纹及种子定义 |
| `flowchart_store.py` | SQLite初始化、按项目读取、不可变版本、并发保存事务 |
| `ui/algorithm_flowcharts.py` | 每浏览器目录、草稿、预览、切换保护和保存／导出状态 |
| `ui/flowchart_canvas.py`及配套JS | Mermaid渲染协议、SVG有效性、画布操作、节点选择和SVG下载 |
| `resources/`中固定mmd／注释 | 用户提供的航信样例，不依赖桌面文件或本任务目录 |

Workbench为algorithms路由调用独立View，主题更新调用其set_theme，项目切换与离页增加草稿保护；不改变其他分析View的dirty/loading含义。无项目时沿用现有先选项目行为；华师大／大润发的算法模块为空目录而不是航信内容。

本任务不打开现场连接；运行、控制、参数发布以及从可执行代码自动生成图都不在本次接口中。保持统一启动文件同时加载既有航班和小麦数据源，预览新模块时不得遗漏旧配置。

## 8. 兼容与风险

- 本地存在其他任务新增的AHU回风温度、每日用电占比及多处未提交工作，实现前重新读取当前代码，只编辑集成相关区块，不回退或混入它们。
- Mermaid版本以本地NiceGUI打包版本为准；官方最新文档只作能力依据，不能直接采用新版语法而未验证本地兼容性。
- 浏览器端渲染验证不是执行权限或控制授权，图示保存也不发布算法。对未知源码只提供图示，不推断“真实参数已配置”。
- 新增本地SQLite后需要验证写入失败、版本冲突与重启，不将仅浏览器内存演示当成持久化完成。用户草稿未保存不会跨崩溃恢复，页面须明确状态。
- 回滚移除算法路由和新增组件即可恢复占位页，本地数据库保留，不删除用户图示；不改现场数据。

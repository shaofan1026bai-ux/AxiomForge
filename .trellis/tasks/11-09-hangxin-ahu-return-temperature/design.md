# AHU 回风温度：详细设计草案

状态：2026-11-09 用户已确认跨午夜按开始日期归属，最后一天延伸次日，并批准开始实现。

## 1. 页面结构

航信机场项目专题增加“AHU回风温度”，与功率温度、今日航班并列，既有默认项目入口不变。标题“AHU回风温度分析”，副标题“芒市机场 · AHU1～5”，环境“小麦只读”，沿用Research Canvas与亮／暗／系统主题。

主页面：标题与查询时刻 → 查询栏 → 成功快照的实际范围／状态 → 页签“总览对比／逐日与明细／数据质量与口径”。总览优先展示五行对比表，不拆成大量重复设备指标卡。宽屏区间图与温区并排，窄屏上下排列；表格局部滚动，不缩小关键文字。验收尺寸1440×1024与1280×800。

## 2. 查询与日期规则

| 控件 | 行为 |
|---|---|
| 日期预设 | 昨天、近7个完整日、本月截至昨天、自定义；无偏好默认近7个完整日 |
| 日期范围 | UI起止日期均包含；全天实际为开始日00:00至结束日次日00:00，结束不含 |
| 每日固定时段 | 默认关闭，即全天；开启显示分钟精度的开始／结束时刻 |
| 范围摘要 | 例如“10月1日—11月8日，每天14:00—18:00，39个窗口／156小时，北京时间” |
| 查询统计 | 冻结合法提交、解析全部窗口，再手动取数；禁重复提交 |
| 恢复默认 | 只改草稿为近7个完整日／全天，不自动取数或改旧快照 |
| 导出 | 汇总／逐日／温区／质量CSV，只用成功快照 |

相对日期预设记住规则，重新打开按现场日期计算；自定义日期保持字面。每月1日“本月截至昨天”没有完整日，禁用并解释，不回退成上个月。首版查询完整已结束窗口，包含未来窗口时先提示修改，不悄悄截断为半天并称为全天。

开启时段后，无历史时刻偏好时推荐控件初值09:00—18:00，须提交才生效。关闭时保留编辑过的时刻但不参与查询。开始=结束为无效，提示“全天请关闭每日固定时段”；结束早于开始则标“次日”。

### 2.1 窗口示例与归属

| 日期与时段 | 解析 |
|---|---|
| 10月1日—3日，全天 | 3个日历日，共72小时；不计10月4日 |
| 10月1日—3日，14:00—18:00 | 每日一个独立半开窗口，共12小时 |
| 10月1日—3日，22:00—次日06:00（提案） | 按开始日归属，最后窗口结束10月4日06:00，共24小时 |

跨午夜最后一天延伸次日，已由用户确认。逐日表按开始日期一行，不午夜拆行；范围摘要明确最后窗口结束时间，该时刻也参与未来校验。所有日期使用Asia/Shanghai，不依赖主机或浏览器时区。

## 3. 总览对比

### 汇总表

固定五台，默认AHU编号排序；可按开机平均或P95排序，空值在最后。字段：设备、全天最低—最高、开机最低—最高、开机主要范围P05～P95、开机平均、有效温度／确认开机样本数、质量提示。启用每日时段后“全天”列改称“所选时段（不限启停）”，避免误读。

表头范围与查询时间来自成功快照，不随查询草稿变化。点击设备展开同一设备详情。原用户表仅作设计参考，首次产品空态不展示它冒充查询结果。

结论如“AHU3开机平均最高”明确排序指标，不能笼统地把最高极值与最高均值混为一谈。并列显示并列；部分设备无开机样本则注明“在有有效开机样本的设备中”。

### 区间图

五台共用摄氏度横轴，每台一行；切换不限启停／确认开机。细线为最低—最高、粗线为P05～P95、圆点为样本平均。不是P25/P75箱线图，标记含义直接显示。无样本保留行并显示文字，不画成0℃。悬停与可访问详情提供精确值和样本数。

### 温区分布

每台一条100%堆叠条，默认确认开机。分桶沿用原脚本：低于20、20～22、22～24、24～26、26～28、28～30、30℃及以上，左闭右开。分母为当前设备、窗口与运行口径的有效温度样本数；显示分子／分母与“有效采样占比”，不叫时长占比或舒适达标率。某设备无样本时不绘制百分比。

## 4. 逐日与详情

逐日按设备、业务日期保留每个窗口，包括无数据日；字段包含实际窗口、两类样本数、两类极值、开机P05/P95/平均与质量提示。默认设备AHU1，切设备只过滤已查询快照。

日变化图展示每天范围带与平均点，缺测日断线；开机／不限启停切换不重查。点击某日定位对应设备窗口，展开回风趋势及独立的反馈／频率轨道；状态未知和明确停机不同标识，不与温度混用数值轴。详情分页显示时间、回风、反馈、频率、状态和字段质量。

详情、图例、排序与缩放只改变查看方式，不改变总体统计或完整范围导出。长范围绘制可保极值降采样，但统计与分位数仍用全部有效点，缺测断点不得被连通。

## 5. 样本与质量合同

### 5.1 身份和时间

项目832，AHU1～5设备依次12783～12787。每台登记`ewcnad_msahu{n}_airin`（℃）、`ewcnad_msahu{n}_v20`（无量纲）、`ewcnad_msahu{n}_v01`（源单位hz，显示Hz）。来自2026-11-09原包点表；每次取数仍检查身份，不按数组顺序／模糊名称匹配。

沿用原分析1分钟查询网格，明确不等于实际传感器上报周期或原始瞬时值。三点按精确时间对齐，禁止最近时刻匹配或前向填充。相同时间同值去重、异值冲突则该字段无效；保留非法时间／越界／非网格等计数。

### 5.2 状态

- 确认开机：反馈=1且频率是有限数值，0<频率≤60Hz，与原表一致。
- 确认停机：反馈=0且频率=0；这比原脚本只看反馈的停机统计严格，原表不包含停机汇总，全天及开机复核不受影响。
- 状态矛盾：反馈=1且频率=0，或反馈=0且频率为正；单独标明，不作为开机或停机。
- 未知／无效：字段缺失、非法反馈、非有限／负频率／超过60Hz；保留具体原因。
- 分类按优先校验字段，再判一致性，规则互斥完备。温度是否有效独立于运行状态：温度缺失不自动改变反馈状态。

### 5.3 统计

不限启停使用窗口内所有有效回风数值；开机使用其中同刻确认开机的交集。有限真实0保留；布尔值非数值，null不补0，无温度极值阈值裁剪。

平均值为样本算术平均；分位数按排序位置`(n-1)*p`线性插值，与原脚本一致。总体P05/P95从全样本计算，不平均逐日分位数；总体平均按全部样本／样本数合并，不平均日均。单样本可给出相同极值、分位数与平均并提示n=1；零样本为无值。页面1位小数，内部不提前舍入。极值并列显示首次时间与次数。

### 5.4 质量

每台分别显示温度有效n/N、反馈与频率共同有效量、温度有效但状态未确认量、矛盾量、冲突时间戳量、首末有效点、完整无数据日。N只来自实际选中窗口的期望1分钟网格；每日未选时段不计缺测。

“开机有效样本数”不叫开机率，不以已有开机样本自除获得100%。连续缺测只在单个选中窗口内统计，显示首个缺失网格至下一有效网格／窗口结束，并可查看相邻有效点；不跨每日未选时段拼接为故障。没有源质量码时，只能称本次查询未返回有效数据，不能断言传感器损坏或通信故障。

## 6. 记住条件与快照

浏览器键`axiomforge.hangxin.ahu-return-temperature.query.v1`保存版本、项目、日期模式、自定义日期、时段开关与起止时刻。保存最近一次通过本地校验并明确提交的合法条件，而非未提交草稿；上游失败仍保留此合法条件供重试。恢复默认只改草稿，再次提交才覆盖最近条件。

恢复前校验版本、类型、项目、日期和时间；损坏／旧版／不可用存储回退默认，当前会话仍可用。合法自定义日期如今涉及未来窗口则保留表单并提示修改，不发请求。

初进、浏览器刷新及偏好恢复均不自动查询。数据快照仅保留当前浏览器对应的服务端View内存，回到同会话页面可显示旧结果和时间；刷新浏览器后需再查。localStorage不保存原始温度、账号、Token或凭据路径。

首版不增加跨用户服务器持久化缓存、长期快照归档或命名收藏；这些是后续功能。日期预设记住“规则”，自定义记住“固定日期”，二者不能混淆。

## 7. 取数与状态交互

建议边界：领域`ahu_temperature.py`拥有点位、窗口、归一化、统计与CSV；源`ahu_temperature_source.py`复用既有小麦低层认证／只读访问；UI和图表独立模块。不能扩大功率专题的两点POINTS并复用其7天输入类型来隐式改变旧合同。

一次手动查询先冻结条件、核验授权和15点，再分段读取，每片不超过24小时且只覆盖实际窗口；15点批量上限待适配测试，必要时按设备分批。I/O移出UI循环。进度显示实际完成片数x/y、当前日期／批次、已用时间；分母以实际任务拆分计算，不展示虚构剩余时间。现有90秒总截止不能未经实测套用39日15点读取。

停止等待使请求代号失效，后续片开始前检查停止标志；当前已发HTTP请求依赖超时结束，不声称取消服务端SQL。失败、主动停止及离页不发布部分总表；已成功请求的空点是合法缺测，不与网络请求失败混用。

| 状态 | 展示 |
|---|---|
| 未查询／恢复条件 | 显示条件及未查询提示，无伪造0值 |
| 草稿修改 | 保留旧范围，提示待更新，禁导出 |
| 加载 | 旧表标上次结果，显示真实进度，禁重复提交与导出 |
| 成功单台无数据 | 发布完整成功快照，保留5台行并给出空态 |
| 请求失败／停止 | 旧快照保留且明确未更新，不发布部分统计 |
| 切项目／离页 | 挂载和代号失效，迟到结果不污染其他页面 |
| 主题／页签／排序 | 不调用上游，不改变数据范围 |

## 8. 导出与兼容

导出汇总、逐日、温区、质量CSV及口径说明，UTF-8 BOM。每份包含窗口规则、实际首末时间、查询时刻、时区、网格、来源、状态定义与分位数算法版本；逐日保留空日，缺失留空而不是0。全部五台完整提交范围，不随详情、缩放或排序丢行。

继续使用现有外部小麦参数，保留航班／功率配置与联合启动方式；新专题回归不能只测自己。修改共享源函数时保留原公开签名和旧测试。现有工作区多会话修改不得覆盖或混入提交。

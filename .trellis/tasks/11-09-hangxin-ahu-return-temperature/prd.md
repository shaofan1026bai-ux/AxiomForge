# 航信 AHU 回风温度分析专题

状态：2026-11-09 用户已确认跨午夜归属并明确批准按本版设计开始实现。

## 目标与授权

用户经常重复查看航信机场 AHU1～5 在指定时间内的回风温度范围，希望在 AxiomForge 中形成独立专题。2026-11-09 用户明确选择：日期范围叠加可选每日固定时段，默认全天；记住上次查询条件，继续细化设计。用户随后明确批准产品实现，授权范围为本PRD及详细设计。

## 背景与证据

- 既有航信专题沿用 NiceGUI、Research Canvas 与每客户端独立状态。
- 用户39日汇总的原始包、点位清单和统计脚本已找到，详见 `research/evidence.md`。
- 原分析使用1分钟查询网格；开机要求同刻反馈=1且0<频率≤60Hz。网格不是实际传感器上报周期。
- 功率专题的2分钟／7天合同不适用于本专题；新专题至少应支持2026-10-01至11-08的39个完整日。

## 需求

| ID | 要求 |
|---|---|
| R1 | 仅航信提供“AHU回风温度”入口，固定比较AHU1～5。 |
| R2 | 日期范围＋可选每日时段，默认全天、Asia/Shanghai；摘要显示精确窗口。 |
| R3 | 提供昨天、近7个完整日、本月截至昨天、自定义；无偏好推荐近7个完整日。相对预设恢复规则，自定义恢复字面日期。 |
| R4 | 汇总并列不限启停最低最高、开机最低最高、开机P05～P95及样本平均，增加有效样本数与质量提示。每日时段开启时不用“全天”误称统计范围。 |
| R5 | 区间图、逐日汇总、温区分布和设备详情来自同一快照；图例与缩放不改变统计范围。 |
| R6 | 区分温度缺测、状态未知、反馈频率矛盾；温区比例只称有效采样占比，不推断精确时长或舒适达标率。 |
| R7 | 同浏览器按项目及专题保存最近一次合法提交条件，恢复后不自动查询；提供恢复默认。 |
| R8 | 手动查询显示真实分片进度，可停止等待；失败／取消不发布部分总表，旧快照明确标记。 |
| R9 | 可导出成功快照的汇总、逐日、温区与质量；附窗口、统计口径、来源及查询时刻。 |
| R10 | 复用现有只读认证；保留航班、功率专题和联合启动配置，不执行设备控制。 |

## 验收标准

- AC1（R1、R10）：仅航信可进入新专题，其他项目不绕入；既有专题回归通过。
- AC2（R2）：窗口左闭右开，全天不溢出结束日，每日相邻片段不重复；跨午夜按开始日期归属，结束日窗口允许延伸次日。
- AC3（R3、R7）：重开恢复合法提交；相对预设按当前现场日期解析，自定义日期不漂移；非法缓存安全降级，不自动请求。
- AC4（R4、R6）：原39日包相同网格下复核五台样本数、极值、线性分位数及平均；界面1位小数，计算保留精度。
- AC5（R4、R6）：温度有效但状态未知仍参与不限启停统计，不计为确认开机；无有效样本显示空态，不补0。
- AC6（R5）：图表、表格、详情及导出一致；逐日保留无数据日期，温区分桶完整且无重叠。
- AC7（R8）：至少支持39日完整查询；网络片失败不发布新总表，成功空结果明确呈现。
- AC8（R7～R9）：草稿不篡改旧快照范围；待更新、加载或失败时禁用导出，只导出完整成功范围。
- AC9（R10）：亮暗主题、两种桌面尺寸可用；离页迟到响应、项目和客户端互不污染，主题不触发取数。

## 不包含

自动设备控制、温控参数下发、定时查询、跨设备平均替代个体统计、补值、自动剔除温度极值、多每日时段及节假日排班。长期快照归档、服务器历史缓存和命名收藏延后；首版只保存最近条件。

## 已确认产品决策

跨午夜按开始日期归属：日期范围内每天取当天22:00到次日06:00，结束日窗口可延伸到次日06:00；查询前显示真实结束时间。用户已明确确认该规则。
